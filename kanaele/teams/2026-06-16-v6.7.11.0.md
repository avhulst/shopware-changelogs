# Shopware 6.7.11.0 veröffentlicht

**Shopware 6.7.11.0 veröffentlicht** (16.06.2026)

**Features**
- Experimenteller MCP-Server für KI-Integration (/api/_mcp, Feature-Flag)
- Neues Storefront-Komponentensystem (Twig UX) + Vite-Dev-Server
- 7 neue Foreign-Key-Resolver für die Sync API
- Neue Mail-Template-Preview-/Send-Routen

**Stabilität**
- Elasticsearch-Ausfälle brechen Bestellungen nicht mehr ab

**Für Projekte**
- Komponentensystem = Grundlage des kommenden Content-Systems
- watch:storefront deprecated -> storefront:dev-server verwenden
