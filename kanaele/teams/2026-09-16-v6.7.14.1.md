# Shopware 6.7.14.1 veröffentlicht (Security)

**Shopware 6.7.14.1 veröffentlicht** (16.09.2026) - Security-Release

- Webhooks erhalten keine Recovery-/Mail-Events und keine contextToken/confirmUrl/url-Werte mehr
- Apps mit solchen Subscriptions: bis 6.8 umbauen
- PATCH /api/_info/me: avatarMedia nur als ID-Link
- Newsletter-Double-Opt-in konsistent erzwungen
- User-/Integration-Kloning über Admin API entfernt
