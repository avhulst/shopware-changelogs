# Shopware 6.7.11.0 für Entwickler

Version **6.7.11.0** · veröffentlicht 2026-06-16 · geprüft 2026-11-08

- Experimenteller MCP-Server: Aktivierung über Feature-Flag MCP_SERVER, Endpunkt /api/_mcp (Streamable HTTP). Plugins registrieren Capabilities via Tags mcp.tool, mcp.prompt, mcp.resource; Apps über App-Manifest. CLI: debug:mcp listet alles auf. Auth via Admin-API-Integrations-Credentials (sw-access-key/sw-secret-access-key), ACL wird respektiert, Allowlists pro Integration konfigurierbar.
- Neues Storefront-Komponentensystem auf Basis von Twig UX Components mit SCSS/JS-Support; Grundlage des künftigen Content-Systems, aber schon heute in bestehenden Templates nutzbar (Doku: developer.shopware.com, Storefront Components).
- Neuer Vite-Dev-Server: composer storefront:dev-server (ohne Proxy, SCSS/JS-Hot-Reload); composer watch:storefront ist für die nächste Major-Version deprecated.
- Theme-Konfiguration jetzt als native CSS Custom Properties verfügbar (var(--sw-color-brand-primary) usw.) - Schritt weg von PHP-SCSS-Kompilierung; theme.json unterstützt Einzeldatei-Referenzen (@MyTheme/app/storefront/src/scss/overrides.scss).
- Sync API: 7 neue Foreign-Key-Resolver (currency.iso_code, locale.code, payment_method.technical_name, shipping_method.technical_name, document_type.technical_name, salutation.salutation_key, tax.tax_rate; bei tax_rate nur eindeutige Treffer).
- Mail-Templating: neue Admin-API-Routen /api/_action/mail-template/simulate, /preview, /get-data-and-send, /available-variables; Preview sales-channel-aware mit Header/Footer; extensions-Bag im send-Payload (unbekannte Top-Level-Keys sind deprecated, entfallen in 6.8).
- Core-Details (aus RELEASE_INFO): State-Machine-Übergänge pro Entity gelockt; Order-Deep-Link-Ablauf konfigurierbar; media:delete-unused ignoriert technische Zuordnungen optional; invalide Locales abwärtskompatibel; Plugin-Snippets werden nicht mehr still verworfen; installation order requirement-aware.
- Storefront-JS: neues globales Event-System window.Shopware.on/emit (interceptable Events, z.B. Request-Parameter vor Versand ändern); PluginManager.callPluginMethod(pluginName, methodName, ...args).
- Administration (aus RELEASE_INFO): Block-Renaming im CMS, Custom Fields respektieren Read-Only-Berechtigungen, sw-date-filter 'Letztes Quartal'-Fix, Meteor Component Library 4.28.6, Theme-Vererbung für Boolean-Felder gefixt.
- Hosting (aus RELEASE_INFO): lokale Filesystem-Rechte-Enforcement abschaltbar; partielle Filesystem-Visibility-Overrides erhalten Adapter-Konfiguration.
- Deprecations: RegisterScheduleTaskMessage, watch:storefront, unbekannte Top-Level-Keys im mail-template/send-Payload.
- Critical Fix: Elasticsearch-Transport-Fehler beim Indexing werden gefangen (ElasticsearchHelper::allowIndexing); Bestellungsabschluss bleibt bei SHOPWARE_ES_THROW_EXCEPTION=0 stabil.
