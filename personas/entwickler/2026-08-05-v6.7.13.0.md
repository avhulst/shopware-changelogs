# Shopware 6.7.13.0 für Entwickler

Version **6.7.13.0** · veröffentlicht 2026-08-05 · geprüft 2026-11-08

- Critical Fix: Store-API-Requests starten keine PHP-Sessions mehr - Subscriber, die Sessions in Store-API-Requests nutzen, müssen das jetzt explizit tun.
- Custom Fields deklarativ: Resources/config/custom-fields.xml (inkl. searchable); die 6.8er-Doku beschreibt die Migration von Runtime-Custom-Fields.
- Neues Criteria::excludeFields() reduziert Entity-Reads; OneToMany-Limit respektiert Sortierung über Joins; Not-Null-Translationspalten akzeptieren falsy Defaults.
- Scheduled-Task-Ausführung in ScheduledTaskExecutor ausgelagert; Shopware-Services und Übersetzungen werden automatisch per Scheduled Task aktualisiert.
- Store API: OpenAPI JSON-Schema-Dateien haben Vorrang vor generierten Entity-Schemas; Purchase-Prices entfernt aus Order-Line-Item-Payloads; ACL-Expansions-Verhalten von DAL-Write-Listenern korrigiert.
- Admin API: Übersetzungs-Downloads und Media-Downloads steuerbar (Manage translation downloads / Download media files via the Admin API).
- Storefront: Link-Kategorien bekommen wieder SEO-URLs; paginierte URLs haben eindeutige Canonical-URLs; robots.txt erlaubt Produkt-Feed-Tracking-URLs; Formular-Validierung via Snippets steuerbar.
- Rule Builder (aus RELEASE_INFO): All-/Mindestens-ein-Toggle config-basiert; Line-Item-Einkaufspreis mit Netto/Brutto-Typfeld; dynamische Produktgruppen entgruppiert matchbar.
- App System (aus RELEASE_INFO): Tax-Provider-Priorität bleibt über App-Updates erhalten.
- Hosting (aus RELEASE_INFO): GENERATE_SOURCEMAPS-Umgebungsvariable für Production-Builds.
- Deprecations (aus RELEASE_INFO): BeforeCacheControlEvent + Admin-Cache-Control-Marker, EntitySearchResult-Subklassen, UnmappedFieldException (DBAL-Sub-Namespace), inline <custom-fields> im App-Manifest, maintenanceIpWhitelist-Wording, AbstractDomainLoader::load() zugunsten loadDomains(), Address-Manager-Typ-Variable.
- CLI: plugin:create mit --no-scaffold; Mail-Template-Simulation mit Formulardaten.
