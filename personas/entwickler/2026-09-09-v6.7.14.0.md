# Shopware 6.7.14.0 für Entwickler

Version **6.7.14.0** · veröffentlicht 2026-09-09 · geprüft 2026-11-08

- Größtes Release der Nachtragsserie: 85 dokumentierte Einzeländerungen - ACL-Härtung, MCP-Reifung, E-Rechnung, Keyset-Pagination.
- MCP: Server ohne MCP_SERVER-Flag; Toolsets pro Session aktivierbar, On-Demand-Tool-Discovery, Entity-Tools validieren Assoziations-Read-Privilegien, Allowlists vor Pagination, Clients werden bei App-Capability-Änderungen benachrichtigt; debug:mcp zeigt Store-API-Capabilities.
- Admin-API-ACL: Number-range-, SEO-, Media-, Template-Rendering-, Queue-, Increment-, Order-Recalculation/Conversion- und weitere Action-Endpunkte verlangen Privilegien; sw-expect-packages wird auf Endpunkten ohne Auth zurückgewiesen - Integrations- und CI-Zugriffe prüfen!
- Store API: experimenteller Snippet-Endpunkt; Cart-Totals als separates CartPrice-Schema-Dokument; keine Versandarten ohne nutzbaren Preis; Sprachlisten-Validierung gegen Default-Sprache; Newsletter-Routen behalten StoreApiResponse.
- Criteria: resetFields() und resetExcludedFields() neu; Cross-Selling über dynamische Produktgruppe schließt die ganze Variantenfamilie aus.
- E-Rechnung/Dokumente: GARAN-Label und EU-Gesetzgebungshinweis, korrekte Preisbasis-Menge; DocumentV1/V2-Datei-Kompatibilität; VAT-Anzeige hinter 6.8-Feature-Flag.
- Produktexport: --force regeneriert scheduler-verwaltete Exporte; Keyset-Pagination (getTotal() deprecated); Body-Media-URLs RFC 3986 encodiert; Scheduling vom Cache-Timestamp entkoppelt.
- Administration: Vue SFCs für Extensions (Codemod emittiert Setup-Components), System-Config-Forms mit Validierungsfehlern und Sales-Channel-Scope, Meteor-Snackbar global nutzbar, Media-Quick-Info-Extension-Point.
- Storefront: reCAPTCHA-Fehler zeigen keine Fehlerseite mehr bei Non-AJAX-Formularen; theme:create --full und granulare Scaffold-Flags; PluginManager.override() für async Plugins; webpack-Chunk-Loading-Global pro Bundle.
- App System: Recovery ambig fehlgeschlagener Registrierungen; Custom Fields auf Media-Foldern; Media-Folder-Modal publishiert Datasets.
- Hosting (aus RELEASE_INFO): SERVICE_REGISTRY_URL nur auf Shopware-Domains in Production; optionaler Clear-Site-Data-Header bei Logout; Thumbnail-Force-Regeneration/-Deletion via --force.
- Deprecations (aus RELEASE_INFO): XML-Konfiguration (deprecated), getTotal() beim Produktexport, EntitySearchResult behält Entity-Namen (BC-Attribut).
