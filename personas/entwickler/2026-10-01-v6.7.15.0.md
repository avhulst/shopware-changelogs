# Shopware 6.7.15.0 für Entwickler

Version **6.7.15.0** · veröffentlicht 2026-10-01 · geprüft 2026-11-08

- Document Generation v2 (aus RELEASE_INFO): Opt-in via DOCUMENT_GENERATION_REWORK; neue Admin-API-Routen /api/_action/order/document-v2/create, /upload, /preview, /download/{format}, /download-archive, /available-types ( unabhaengig vom Flag verfuegbar).
- DocGen-v2-Extension-Punkte (aus RELEASE_INFO): Plugins registrieren Typen, Data Provider und Renderer als getaggte Services (shopware.document_v2.type/provider/renderer); Apps registrieren Dokumenttypen im <documents>-Manifest-Block plus document-generation App-Script-Hook.
- Zeitplan DocGen (aus RELEASE_INFO): 6.7 opt-in, 6.8 Default (opt-out), 6.9 Entfernung der Legacy-Pipeline und des Flags; Migration in UPGRADE-6.9.md. Legacy-Events und document.renderer-Tags werden von v2 nicht aufgerufen.
- Neue Events document.generation.completed (DocumentGeneratedEvent) und document.generation.deleted (DocumentDeletedEvent), als Flow-Builder-Trigger nutzbar.
- OAuth (aus RELEASE_INFO): Authorization Code Grant mit PKCE am Admin-API-Autorisierungsserver; ApiClient akzeptiert $redirectUris/$grantTypes und supportsGrantType(); oeffentliche Clients nur authorization_code und refresh_token.
- MCP (aus RELEASE_INFO): Toolsets per URL-Parameter (?toolsets=...) zur Verbindungszeit waehlbar; MCP-Server deklarativ registrierbar.
- #[ExperimentalReplacement] ersetzt vorzeitige @deprecated-Markierungen fuer Klassen mit experimentellem Ersatz.
- Caching (aus RELEASE_INFO): sw-include-seo-urls in Vary/Cache-Key aufgenommen; No-Vary-Search-Header auf cachebaren Antworten; eigene Cache-Keys um den Header ergaenzen.
- Admin-UI-Shell-Rework: entfernte Twig-Bloecke, umstrukturierte Bloecke in sw-page.html.twig; Plugins mit Admin-Twig-Overrides pruefen.
- Snippets/Themes (aus RELEASE_INFO): Themes erben Snippets aus jedem Theme in configInheritance; statische Theme-Kompilierung ohne Datenbank moeglich.
- Media (aus RELEASE_INFO): Timeouts fuer Remote-Media-Requests konfigurierbar; MailService rendert Mails mit den Snippets ihres Sales Channel.
