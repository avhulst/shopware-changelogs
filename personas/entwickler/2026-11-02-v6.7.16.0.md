# Shopware 6.7.16.0 für Entwickler

Version **6.7.16.0** · veröffentlicht 2026-11-02 · geprüft 2026-11-08

- Rule-Builder-Bedingungen werten wieder alle Line-Item-Typen aus (Fix seit 6.7.14.0); Erweiterungen müssen nichts anpassen.
- SalesChannelContext::getSalesChannel()->getCurrency() liefert wieder die Standardwährung (Regression aus 6.7.15.0 behoben); für die gewählte Währung getCurrency() nutzen.
- Neues Event ProductBackInStockEvent; Subscriber, die auf beide Richtungen reagieren (z.B. Cache-Invalidierung), müssen beide Events abonnieren.
- Deprecations: Dokument-Typen (v6.9), ImportExportProfileTranslation (v6.8), InvalidPriceFieldTypeException -> DataAbstractionLayerException::invalidPriceFieldType().
- HreflangLoaderParameter ohne $homepage-Argument: Fallback auf frontend.home.page ist deprecated, in 6.8 entfernt; Argument explizit übergeben.
- 6.8-Verhalten einzeln voraktivierbar: MEDIA_URL_PATH_ENCODING=1, PROPORTIONAL_CART_TAXES=1, DELETE_CART_AFTER_ORDER_CREATION=1 (Migration in UPGRADE-6.8.md).
- Snippets können jetzt aus dem privaten Filesystem (files/snippets/...) geladen werden; danach cache:clear bzw. Cache-Tag admin-snippet invalidieren.
- System-Konfiguration: Karten können in Tabs gruppiert werden (Beispiel in RELEASE_INFO-6.7.md).
- Apache: aktualisierte .htaccess.dist mit CSP-Headern übernehmen; Installationen ohne Shopware-Update-Marker manuell mergen.
